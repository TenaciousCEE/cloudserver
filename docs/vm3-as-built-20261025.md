passwords, private keys, mailbox contents, database dumps, DKIM key material,
and full configuration files. The separate backup at `/mnt/vm3backup` contains
the protected operational evidence and must not be committed here.

## Scheduled maintenance

The root crontab contains these active operational jobs:

- 09:30 daily: run `sa-learn` against the local spam-learning mailbox.
- 08:30, 12:30, 16:30 and 20:30 daily: check `/var/mail` for unusually
  large mbox files.
- 00:23 on Mondays and Thursdays: run `certbot renew` and reload Postfix,
  Dovecot and Apache through the deploy hook.

The former custom 06:00 SpamAssassin update entry is commented out. Debian's
`spamassassin-maintenance.timer` now performs the rule update, lint/compile
work and `spamd` reload. It runs daily around 06:00 with a random delay and
was verified successfully after the Debian 13 upgrade.

The root crontab also contains disabled legacy Salt backup entries. The
current mailbox/configuration backup is maintained separately from this host
and repository; see the backup references above.
